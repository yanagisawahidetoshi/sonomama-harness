# 秘密情報の扱い

パスワード、APIキー、秘密鍵などの秘密情報を扱うルール（ルールID: SEC-SECRET-001）。

秘密情報は、SBI（AIに渡す作業単位）、ソースコード、AIへの指示文、ログ、検証の記録、レビュー用のZIPのどれにも入れない。
環境設定ファイル、秘密鍵、認証情報を保管するファイル、アップロード用のアクセスキーは、コピーや書き出しの対象から外す。
通常のソースコードや出力に秘密の値が混ざっていないかも検査し、見つけたら伏せ字にするか、変更を適用する前に止める。
この文書は保管場所ではない。実際の値を貼り付けない。

秘密情報に関わる変更には、実装前の人の承認、レベル3のリスク判定、秘密情報の検査（secret-scan）が必要になる（詳しくは[README](README.md)）。
鍵をどこに置き、どう配り、いつ入れ替え、誰が使えるようにするかは、人が別に決める。
